Client technical information

Built as a developer-oriented client.

Duplex Client is distributed as a Nuitka standalone ZIP. Its default GUI is a Python-based ClickGUI provided as an uncompiled Python file and requires the keyboard Python library.

FAQ
What is Duplex Client?+

Duplex Client is a Minecraft Bedrock client centered around access to its modules through a lightweight API and the ability to build your own experience around them.

What makes Duplex different?+

Its module API is designed to expose client functionality without dictating what your interface must look like.

What does the API actually do?+

The API exposes functionality for interacting with Duplex modules, including toggling modules and changing module values.

Is the API a UI framework?+

No. Duplex provides the modules and API access. You build the UI.

Can I build my own UI?+

Yes. The API is intended to give you the building blocks needed to create your own interface or tooling.

Can I use AI or vibecoding?+

Yes. The documentation and API examples can be used as references for AI-assisted development.

Can the documentation change?+

Yes. The API documentation is maintained separately from the landing page and can evolve as the API changes.

How is Duplex distributed?+

As a Nuitka standalone ZIP.

What is the default GUI?+

A Python-based ClickGUI.

Where do I download Duplex?+

Through Discord.

What do the subscription tiers provide?+

The tiers primarily provide different update-delay windows, with Pro including support and Dev / Supporter additionally supporting Duplex development.
